# 快修到家 - 投诉理赔规则

## 一、投诉受理范围

### 1.1 服务类投诉
1. 师傅迟到超过约定时间30分钟
2. 师傅未按预约时间上门且未提前通知
3. 师傅服务态度恶劣
4. 师傅安装技术不达标，安装后产品无法正常使用
5. 师傅中途加价，超出平台报价
6. 师傅未完成安装就离开
7. 师傅接单后无故取消

### 1.2 货损类投诉
1. 安装过程中造成商品外观损坏（划痕、磕碰、破裂）
2. 安装过程中造成商品功能损坏（电路故障、结构变形）
3. 安装过程中造成房屋设施损坏（墙面刮花、地板划伤、打孔位置错误）
4. 运输搬运过程中造成的磕碰损坏

### 1.3 平台类投诉
1. 下单后长时间无师傅接单
2. 平台客服响应慢或处理不当
3. 理赔流程繁琐、处理时间过长

## 二、投诉处理流程

### 2.1 提交投诉
1. 商家/消费者通过平台APP或400热线提交投诉
2. 需提供：订单编号、问题描述、现场照片/视频
3. 投诉时效：服务完成后7个自然日内

### 2.2 平台审核
1. 客服接到投诉后2小时内首次响应
2. 根据投诉类型分配处理专员
3. 一般投诉24小时内给出处理方案
4. 涉及货损理赔的投诉48小时内给出定损结果

### 2.3 处理方案
1. 重新派单免费重装（服务类投诉）
2. 退还安装费并补偿（服务态度类投诉）
3. 按定损金额理赔（货损类投诉）
4. 协商赔偿金额（房屋设施损坏）

## 三、理赔标准

### 3.1 商品损坏理赔
| 损坏程度 | 理赔标准 | 示例 |
|---------|---------|------|
| 轻微外观 | 维修费或赔偿商品价值5-15% | 小划痕、轻微磕碰 |
| 中度损坏 | 赔偿商品价值15-40% | 面板破损、结构松动 |
| 严重损坏 | 赔偿商品价值40-80% | 大面积破损但不影响使用 |
| 完全损坏 | 赔偿商品价值100% | 无法修复、功能完全丧失 |

"商品价值"以商家提供的进货凭证或发票金额为准。

### 3.2 房屋设施损坏理赔
| 损坏情况 | 理赔上限 | 说明 |
|---------|---------|------|
| 墙面（单处） | 500元 | 含修补材料及人工 |
| 墙面（多处） | 2000元 | — |
| 地板/地砖 | 按实际面积 | 最高5000元 |
| 水管/电路 | 按实际维修费 | 最高3000元 |

### 3.3 服务体验补偿
| 投诉类型 | 补偿标准 |
|---------|---------|
| 师傅迟到30-60分钟 | 退还50%安装费 |
| 师傅迟到60分钟以上 | 退还100%安装费 |
| 师傅未上门 | 退还100%安装费 + 100元体验金 |
| 师傅态度恶劣 | 退还100%安装费 + 200元体验金 |

## 四、退款时效
1. 安装费退款：处理方案确认后1-3个工作日原路退回
2. 理赔款：定损确认后3-7个工作日打款
3. 体验金：即时发放至账户余额，可用于下次下单抵扣

## 五、申诉机制
如果商家/消费者对处理方案不满意，可在3个工作日内通过400热线申请升级处理，由高级客服经理介入复核。
